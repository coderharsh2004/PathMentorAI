## 🚀 Overview  
**PathMentorAI** is an **AI-powered career guidance platform** designed to help students and professionals navigate their career journeys with confidence.  
It delivers **personalized career paths, resume feedback, and skill roadmaps** using the **Gemini API**, empowering users to enhance their **career readiness** and **skill development**.  

The platform currently supports **100+ users** with secure authentication and scalable performance.  

---

## ✨ Key Features  

- 🎯 Personalized career path recommendations powered by GenAI  
- 📄 AI-based resume tips and improvement suggestions  
- 🛠️ Skill roadmap generation for structured upskilling  
- 🔐 Secure authentication & session management via Clerk  
- 🗄️ Serverless PostgreSQL database ensuring **100% data integrity**  
- ⚡ Scalable performance handling **150+ active users**  

---

## 🛠️ Tech Stack  

- **Frontend:** Next.js, Tailwind CSS  
- **Backend:** Next.js API Routes (Serverless)  
- **Database:** PostgreSQL (Serverless)  
- **Authentication:** Clerk  
- **AI Integration:** Gemini API (Google GenAI)
